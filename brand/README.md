# StormFile icon files

`icon.svg` is the master artwork (sharp at any size). Everything else is made from it.

| File | Where it goes |
| --- | --- |
| `appstore-icon-1024.png` | Apple App Store / Xcode app icon (1024 × 1024, no transparency; Apple rounds the corners) |
| `play-store-icon-512.png` | Google Play listing icon (512 × 512) |
| `android-adaptive-foreground.png` + `android-adaptive-background.png` | Android adaptive launcher icon layers (432 × 432). The art sits inside the safe zone so circle and rounded masks don't cut the lettering |
| `../icon-192.png`, `../icon-512.png`, `../icon-maskable-512.png`, `../apple-touch-icon.png` | Web app (home screen) icons |

Font for the lettering: Poppins Bold (SIL Open Font License).
